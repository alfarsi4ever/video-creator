# Director's Brief -- template

Fill this in (save as `brief.md` in the project) before writing any code. Keep each section short.
Leave a section as "n/a" rather than deleting it, so nothing is silently skipped.

```markdown
# Brief: <working title>

## 1. The film in one line
<What the viewer should feel/understand, and the call to action. e.g. "Show that X turns a sketch
into a working app in seconds; end on 'Try it free'.">

## 2. Format
Duration: <15 s>   Aspect: <16:9 1920x1080 | 9:16 1080x1920 | 1:1 1080x1080>   FPS: <30>
Route: <A code-drawn | B Remotion/HyperFrames | C mixed | D footage edit>

## 3. References and inputs
- Brand URL / assets: <...>  -> brand.md
- Reference video (style only): <...>  -> style_guide.md
- Screenshots / UI to feature: <...>

## 4. Tools and keys
<TTS / voice tool, image generator, music source. Note which are connected and which are missing.>

## 5. Visual assets / character notes
<Recurring elements: product UI components, mascot proportions and expressions, icon set.>

## 6. Beat sheet
| # | Start | Dur | On screen | Text | Sound event |
|---|-------|-----|-----------|------|-------------|
| 1 | 0.0 | 2.0 | Hook: ... | ... | downbeat hit |

## 7. On-screen text rules
<Font, weights, max words per card, placement, animation style for type.>

## 8. Workflow gates
Script -> stills (one key frame per shot) -> animatic (rough timing) -> polish -> sound -> final.
<Mark which gates need user sign-off.>

## 9. Critique thresholds
All 7 axes >= 8/10 (Hook, Readability, Motion quality, Variety, Brand, Sound, Depth), max 3 passes
without improvement.

## 10. Deliverables
out.mp4 (H.264, yuv420p, CRF 18), poster.png, source project; extra aspects: <...>
```
