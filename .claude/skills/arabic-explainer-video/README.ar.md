# فيديو شرح عربي — Skill لـ Claude Code

هذه الـ skill تجعل Claude يصنع فيديو عربياً بتعليق صوتي عن أي فكرة (تاريخ، سيرة، علوم، درس
مدرسي، قانون، نظام، منتج، قصة…)، كله من الكود:
تكتب (أو يكتب Claude) النص ← Gemini يولّد الصوت ← مدة كل جملة تحدد توقيت ظهور العناصر ←
متصفح Chrome يلتقط الإطارات ← ffmpeg يجمعها في ملف MP4.

تصلح لشاشة التلفاز (16:9) والهاتف (9:16)، وتدعم أسئلة بعدّاد زمني بعد كل قسم.

## ما في المجلد

| المسار | ما هو |
|---|---|
| `SKILL.md` | التعليمات التي يقرؤها Claude (سير العمل كاملاً) |
| `references/` | قواعد كتابة النص المنطوق، قواعد التصميم، أشكال الفيديو حسب نوع الموضوع (`topics.md`)، حل المشكلات |
| `scripts/` | خط الإنتاج: `tts` الصوت، `verify` التحقق، `timeline` التوقيت، `render` الإطارات، `encode` الملف النهائي |
| `lib/` | مكتبة Gemini TTS وتقطيع الصوت، وقراءة المشروع |
| `template/` | قالب مشروع جديد (انسخه وابدأ منه) |
| `examples/contract-check/` | مثال كامل للتلفاز: فحص امتثال عقود العمل (2:36) مع الفيديو الناتج |
| `examples/drug-law-quiz/` | مثال كامل للهاتف: شرح قانون مكافحة المخدرات مع 20 سؤالاً (13 دقيقة) مع الفيديو الناتج |

## المتطلبات (مرة واحدة)

1. **Node.js** إصدار 20 أو أحدث.
2. **ffmpeg** مثبت ومتاح في PATH.
3. **Google Chrome** مثبت.
4. **مفتاح Gemini API** خاص بك من <https://aistudio.google.com/apikey> — المفتاح غير مرفق في هذا المجلد.
5. خط **Dubai** (يأتي مع Windows/Office). بدونه يُستخدم خط عربي بديل وقد يتغير شكل الأسطر.

## التثبيت

1. انسخ المجلد `arabic-explainer-video` كله إلى مجلد الـ skills:
   - Windows: `C:\Users\<اسمك>\.claude\skills\arabic-explainer-video`
   - macOS / Linux: `~/.claude/skills/arabic-explainer-video`
2. داخل المجلد المنسوخ نفّذ:
   ```bash
   npm install
   ```
3. انسخ `.env.example` إلى `.env` وضع مفتاحك فيه:
   ```
   GEMINI_API_KEY=مفتاحك
   ```
   لا تشارك ملف `.env` مع أحد.
4. أعد تشغيل Claude Code.

## الاستخدام

افتح Claude Code في مجلد فارغ (مجلد لكل فيديو) واكتب مثلاً:

> ‎/arabic-explainer-video اريد فيديو شرح لنظام الإجازات، لشاشة الهاتف، وبعد كل قسم أسئلة. أعطني النص أولاً.

اذكر في طلبك: **الشاشة** (تلفاز أو هاتف)، **الجمهور** (متخصصون أم عامة)، **هل تريد أسئلة**، و**المصدر** (نص القانون أو وصف النظام).

## التشغيل اليدوي (بدون Claude)

من داخل مجلد المشروع (نسخة من `template/`):

```bash
node <skill>/scripts/tts.mjs --list     # كم طلباً سيستهلك
node <skill>/scripts/tts.mjs            # توليد الصوت
node <skill>/scripts/verify.mjs         # مطابقة الصوت مع النص
node <skill>/scripts/timeline.mjs       # التوقيت
node <skill>/scripts/render.mjs --stills # لقطة لكل مشهد للمراجعة
node <skill>/scripts/render.mjs         # كل الإطارات
node <skill>/scripts/encode.mjs --small # out.mp4 + نسخة خفيفة للإرسال
```

لتجربة أحد المثالين دون استهلاك حصة الصوت (الصوت مرفق في `build/batch/`):

```bash
cd examples/contract-check
node ../../scripts/tts.mjs && node ../../scripts/timeline.mjs && node ../../scripts/render.mjs && node ../../scripts/encode.mjs
```

## أمور يجب معرفتها

- **حصة الصوت المجانية محدودة**: نحو 10 طلبات يومياً لكل نموذج، وتُحسب لكل مشروع Google لا لكل مفتاح.
  لذلك يُرسل النص على دفعات (حتى 40 جملة في الطلب) ثم يُقطَّع. راجع النص جيداً قبل توليد الصوت.
- **Claude لا يسمع الصوت.** يتحقق من الكلمات بتفريغ المقاطع آلياً، لكن النطق والتشكيل تراجعهما أنت بالاستماع.
- **السرعة**: `tempo` في `script.mjs` (1.0 كما نُطق، 1.08 مريح، 1.2 سريع للمتخصصين). تغييرها لا يستهلك حصة.
- **المحتوى القانوني**: تأكد أن النص المشروح هو النافذ حالياً، وراجع أرقام المواد قبل النشر.
- مجلد `frames/` يكبر كثيراً (نحو 3 غيغابايت لفيديو 13 دقيقة) ويمكن حذفه بعد الترميز.

تفاصيل الأعطال الشائعة في `references/troubleshooting.md`.
